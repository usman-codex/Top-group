# Media Directory Structure

Place your uploaded media files here so they can be served as static assets in the app:

- `/public/media/images/` - Upload company cover photos and general images here.
- `/public/media/videos/` - Upload video clips (MP4/WebM) here for auto-play hover effects.
- `/public/media/logos/` - Upload company logos and brand assets here.

### Usage in Code / Mock Data:
- Images: `/media/images/your-image.jpg`
- Videos: `/media/videos/your-video.mp4`
- Logos: `/media/logos/your-logo.png`
